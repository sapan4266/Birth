FOREVER BIRTHDAY WEBSITE

1. Extract this folder.
2. Open index.html in Chrome/Edge to preview.
3. Add your photos into assets/photos/ using photo-1.jpg ... photo-6.jpg.
4. Add your MP4 clips into assets/videos/ using video-1.mp4 and video-2.mp4.
5. Personalize the letter in letter.html and the timeline in memories.html.
6. Change the name/relationship wording if you want, and edit the captions in gallery.html.
7. To publish, upload the whole folder to GitHub Pages, Netlify, or another static hosting provider. Keep the assets folders and relative paths unchanged.

PAGES
- index.html: welcome/home
- memories.html: memory timeline
- gallery.html: responsive photo gallery + click-to-expand lightbox
- videos.html: local MP4 video gallery
- letter.html: birthday letter
- surprise.html: interactive gift reveal

No frameworks or build tools required. Works with plain HTML, CSS and JavaScript.
